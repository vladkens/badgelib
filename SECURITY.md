# Security Policy

## Supported Versions

Security fixes target the current release line. Users should upgrade to the latest version compatible with their environment to receive them. Reports affecting older versions are still welcome and will be evaluated against the current codebase.

## Reporting a Vulnerability

Please report security vulnerabilities by email to [security@vladkens.me](mailto:security@vladkens.me). If the issue contains sensitive details or a working exploit, do not open a public GitHub issue until a fix is available.

Include the affected version, a description of the impact, and enough information to reproduce the issue when possible. Reports made through other channels are also welcome, but email is preferred for private coordination.

Confirmed vulnerabilities will be investigated and fixed as soon as practical. A new release and a public security advisory will be published when appropriate.
